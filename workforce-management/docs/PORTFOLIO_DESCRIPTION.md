## 2. GITHUB REPOSITORY DESCRIPTION (README PREVIEW)

### InnovateCorp HRvantage — Enterprise Workforce Management & AI Automation Platform

InnovateCorp HRvantage is an open-architecture Human Resource Management System (HRMS) and Workforce Management (WFM) platform engineered for modern mid-to-large enterprises. It unifies core HR operations—biometric and GPS geofenced attendance, shift allocation, multi-tier leave approval, timesheet client billing, and automated payroll—with predictive AI intelligence and a grounded RAG conversational assistant.

### Key Highlights:
- **High-Throughput ASGI Backend:** FastAPI (Python 3.12) exposing 141 REST operations across 118 paths with sub-20ms average response times.
- **Modern Responsive Frontend:** React 19, TypeScript, and Vite with offline PWA support, vanilla CSS design tokens, and Three.js 3D WebGL visualizations.
- **Predictive AI Intelligence:** 6 machine learning models for absenteeism prediction, attrition risk scoring, attendance anomaly detection, and 30-day demand forecasting.
- **Grounded RAG Assistant:** HR policy chatbot with speech-to-text, verifiable document citations, adversarial guardrails, and pre-retrieval RBAC authorization.
- **Enterprise Security:** Stateless HMAC-SHA256 JWT auth, bcrypt password hashing, 4-tier RBAC, OWASP security headers, and SlowAPI rate limiting.
- **Exhaustive Automated Testing:** 100% pass rate across 99 backend Pytest tests, 35 frontend Vitest tests, and 32 database relational integrity checks.

## 3. LINKEDIN PROJECT SHOWCASE POST

🚀 **Excited to share my latest enterprise project: InnovateCorp HRvantage — an AI-Powered Workforce Management Automation System!**

Traditional HR software is often siloed, slow, and purely reactive. I wanted to build an enterprise platform that bridges daily operational workflows with predictive intelligence and privacy-first conversational AI.

Here’s what I built:

🔹 **Full-Stack Architecture:** Built with **FastAPI (Python 3.12)**, **React 19 (TypeScript)**, **Vite**, and **MongoDB 7.0**, exposing 141 REST operations with sub-20ms average response times and sustained throughput >162 requests/sec.  
🔹 **Operational HR Automation:** Geofenced GPS attendance across multi-campus facilities, rotational shift scheduling with peer swap approvals, multi-tier leave tracking, and attendance-synchronized payroll calculation.  
🔹 **Predictive Workforce Intelligence:** Developed machine learning models using **Scikit-learn** and **Statsmodels**, including Random Forest absenteeism prediction, Gradient Boosting attrition risk scoring, and Isolation Forest attendance anomaly detection. Crucially, all AI operates under a **Human-in-the-Loop** ethical framework—decision support only, with zero autonomous punitive actions.  
🔹 **Grounded RAG HR Assistant:** A conversational assistant that answers complex HR policy questions with exact citations. To prevent unauthorized data leaks, I implemented an **Authorization Gate** that enforces RBAC *before* executing vector search or database queries.  
🔹 **Enterprise Security & Reliability:** Enforced 4-tier Role-Based Access Control, stateless JWT authentication, OWASP security headers, and rate limiting. The platform is backed by a comprehensive automated test suite with **100% pass rates** across 99 backend tests, 35 frontend tests, and 32 database constraint checks on an exact 200-employee baseline.

Check out the architecture and demo runbook in the repository! Feedback and questions are welcome.
